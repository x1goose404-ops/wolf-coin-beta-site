FAQ

What exactly am I buying?

A 1-of-1 NFT (a real SPL token with Metaplex metadata, max_supply = 1) plus the exact 5 XNT locked in a vault that only the current NFT holder can release. Transferring the NFT transfers the claim; redeeming burns the NFT and returns the backing.

Is the collateral really on-chain?

Yes. Each mint deposits exactly collateral_lamports into a per-serial vault PDA. The contract checks this on-chain — the website only helps you build the transaction; it does not enforce anything.

Can the team take my XNT, or mint more later?

No. The reviewed program exposes exactly three instructions — initialize_registry, mint_coin, redeem — with no recovery, admin withdrawal or backdoor. Supply is capped at 10 serials; each serial can be minted once and is retired after redeem.

What happens if I burn the NFT in my wallet by accident?

The redemption right is lost and the backing becomes unrecoverable. That is a deliberate design choice, not a bug. Use the site's Redeem to burn safely.

Where is the artwork stored?

The art is a sealed X1 Vault inscription (…). This site bundles the exact inscribed bytes (BLAKE3 …) so it needs no x1vault.com gateway. Wallets read metadata from a CDN base your on-chain NFT points to — see the security note.

Do you ever need my seed phrase?

Never. This site has no backend and no keys. Your wallet signs; we only build the transaction. Any site that asks for a seed phrase is stealing from you.
